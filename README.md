## AgriSmart

Farm pond liner sales, installation and commission management for
AgriSmart Farm Solutions LLP, Sangamner.

Lifecycle: Lead -> Qualified -> Surveyed -> Quoted -> Order Booked -> Dispatched
-> Delivered -> Installing -> Completed -> Commission Claimed -> Closed.

### Requirements
- Frappe Framework v15 or v16
- ERPNext v15 or v16

### Installation
    bench get-app https://github.com/rskshirsagar/agrismart.git
    bench --site <site> install-app agrismart
    bench --site <site> migrate
    bench build --app agrismart
